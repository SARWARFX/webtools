IN-DEPTH GUIDE // CLIENT-SIDE BATCH PHOTO WATERMARKING & MEMORY ARCHITECTURE

Understanding relative typography scaling, offscreen canvas rasterization, serial async queues, and browser memory preservation.

The Challenge of Batch Image Processing

Commercial watermarking services traditionally force users to upload their high-resolution photography collections to remote cloud servers, incurring privacy risks, bandwidth bottlenecks, and subscription paywalls.

Conversely, executing batch tasks inside a browser tab requires strict memory stewardship. Decoding 100 uncompressed 24-megapixel camera images simultaneously into memory would demand over 8 gigabytes of RAM, causing the browser tab to immediately crash with an Out-of-Memory (OOM) fault.

Serial Queue Pipeline & Relative Scaling

CyberTools executes an asynchronous serial processing pipeline:

  • Transient Decoupling: Images are processed one by one. The image is drawn onto an isolated offscreen canvas, stamped, exported to a Blob, added to the in-memory JSZip instance, and immediately destroyed using URL.revokeObjectURL().
  • Proportional Relative Scaling: Fixed-pixel fonts look huge on 720p photos and invisible on 4K files. CyberTools calculates watermark typography and logo dimensions relative to base image width (fontSize = width * scaleRatio), ensuring uniform visual weight across mixed aspect ratios.

Frequently Asked Questions

Are my original photos uploaded to any server?

Zero uploads. Everything executes directly inside your browser memory using the HTML5 Canvas 2D Context API and client-side JSZip bundler.

Can I batch process 100+ photos at once?

Yes. The asynchronous serial queue processes one image at a time with automatic garbage collection, allowing queues of hundreds of photos without tab memory crashes.

How do dynamic tags like {filename} and {date} work?

During serial processing, the engine dynamically substitutes {filename} with the current photo's base file name and {date} with the current ISO date stamp.

What is the Readability Shield?

It adds a high-contrast dark stroke outline and customizable drop shadow behind your watermark text, ensuring readability whether overlaid on bright snow or dark shadows.
