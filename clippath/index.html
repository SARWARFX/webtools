1. Coordinate Reference Systems (CSS Masking Module 1)

        

          The CSS clip-path: polygon(x1 y1, x2 y2, ...) property establishes a 2D bounding polygon within the element's coordinate space. Points are ordered clockwise or counter-clockwise, with (0%, 0%) anchoring the top-left vertex and (100%, 100%) marking bottom-right.
        

        

          Browsers execute clipping prior to final compositor paint passes. Unlike legacy PNG alpha masks that demand megabytes of texture memory, CSS vector polygon clipping executes directly within GPU fragment shaders with zero additional network or memory footprint.
