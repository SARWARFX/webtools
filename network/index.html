IN-DEPTH GUIDE // CLIENT-SIDE NETWORK TELEMETRY & LATENCY ANALYSIS

Understanding browser uplink diagnostics, NetworkInformation API limitations, and accurate RTT measurement.

What is Network Telemetry?

Network Telemetry provides real-time visibility into the performance, quality, and connectivity state of a client's link to the Internet. Through modern browser APIs such as the NetworkInformation API (navigator.connection), web applications can intelligently adapt their asset delivery based on estimated bandwidth, round-trip latency, and user data-saving preferences.

When users traverse high-speed fiber, 5G cellular, or satellite uplinks with fluctuating latency, this tool calculates actual client round-trip times (RTT) directly inside your browser memory without invoking external tracking servers.

Key Metrics Explained

  • Effective Connection Type (ECT): Classifies current network conditions into buckets (slow-2g, 2g, 3g, or 4g) based on recent observed RTT and downlink throughput.
  • Downlink: Estimated network speed in Megabits per second (Mbps), rounded to nearest intervals to protect user fingerprinting.
  • Round-Trip Time (RTT): The estimated duration in milliseconds for an IP packet to travel from client to server and back at the transport layer.
  • Data-Saver Mode: Indicates whether the client operating system or browser has enabled bandwidth conservation mode.

Frequently Asked Questions

Why does my 5G or Gigabit connection show as '4G'?

The W3C Network Information API specification defines 4g as its highest classification category. Any modern connection exceeding ~10 Mbps with low latency is categorized as 4g by browser design to avoid granular device fingerprinting.

How does the RTT Latency probe measure ping?

The probe issues lightweight, timestamped HTTP HEAD/GET requests with high-resolution performance timers (performance.now()) directly to your local edge CDN node with unique cache-busting query tokens.

Does this tool track my IP or location?

No. CyberTools operates on a strict zero-backend client-side policy. All diagnostics, event logs, and ping calculations occur in transient browser memory.

Which browsers support the Network Information API?

Chromium-based browsers (Chrome, Edge, Brave, Opera) provide full support for navigator.connection. Firefox and Safari support navigator.onLine and the interactive RTT latency probe.
