UNIX DISCRETIONARY ACCESS CONTROL (DAC) & PERMISSION ARCHITECTURE

Technical specifications for POSIX permission bits, octal calculation mathematics, symbolic operators, and hardened security best practices.

1. Binary Weight Mathematics

Unix file permissions are implemented as a set of 9 primary bit flags organized into three distinct triplets (User, Group, Other). Each bit corresponds to an exact power of two:

  • Read (r): Bit value 4 (binary 100). Grants read access to file contents or directory file listings.
  • Write (w): Bit value 2 (binary 010). Grants file modification and directory file creation/deletion rights.
  • Execute (x): Bit value 1 (binary 001). Grants binary program execution or directory directory-traversal (cd).

2. Standard Security Baselines

Hardened POSIX environments enforce strict principle of least privilege permissions:

600 / 400 (Private Keys) Required by OpenSSH for id_rsa and TLS private keys. The SSH client will reject keys with group/other permissions.
644 (Static Assets) Standard baseline for HTML, CSS, JS, and server assets. Owner can write; world can only read.
755 (Executables) Standard for system binaries, shell scripts, and web server directories allowing directory traversal.
