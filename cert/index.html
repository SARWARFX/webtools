X.509 PUBLIC KEY INFRASTRUCTURE (PKI) ARCHITECTURE

X.509 certificates form the cryptographic foundation of Transport Layer Security (TLS/HTTPS). Encoded in ASN.1 DER and serialized to ASCII PEM containers, they bind cryptographic public keys to authorized domain identities:

Subject Alternative Names (SANs) Modern browser trust stores mandate SAN entries for hostname verification, deprecating the legacy reliance on single Common Name (CN) attributes.
Validity Envelopes Strictly bounded between `notBefore` and `notAfter` timestamps. Browsers reject any certificate accessed outside this temporal window.
Zero-Trust Inspection Unlike external SSL checker endpoints that make unauthenticated outbound network scans, this tool parses your raw PEM certificate locally in your browser memory.
