1. Syntax Anatomy & Multi-Layer Compositing

        

          A single CSS box-shadow layer accepts up to six parameters: [inset] ⟨offset-x⟩ ⟨offset-y⟩ ⟨blur-radius⟩ ⟨spread-radius⟩ ⟨color⟩:
        

        
    
          
  • Blur Radius: Rendered using a Gaussian blur algorithm. Per W3C specs, a blur radius of r creates a soft gradient spanning twice the radius length.
    • 
          
  • Spread Radius: Expands (positive values) or contracts (negative values) the shadow's perimeter uniformly in all directions before applying Gaussian filtering.
    • 
          
  • Layering Multiple Photons: By chaining comma-separated layers, designers mimic physical light dispersion: an intense tight inner core paired with a wide, low-opacity ambient diffusion plume.
    • 
        

      


      

        
2. GPU Fragment Shader Considerations

        

          Excessive box-shadow blur values on dynamically animating elements trigger full-layer GPU raster invalidations. Keeping spread values compact and combining static box-shadows with CSS transforms prevents mobile frame drops while maintaining rich cyberpunk luminescence.
