In-Memory PDF Engine

Traditional web-based PDF utility sites require users to transmit confidential tax filings, legal agreements, and corporate disclosures to remote cloud servers. CyberTools eliminates this compliance hazard by running a complete PDF parser and bytecode compiler inside your web browser.

  • Merge Synthesis: Leverages PDFDocument.create() and copyPages() to combine arbitrary document structures with zero layout degradation.
  • Targeted Extraction: Extracts individual page objects into newly synthesized PDF containers, preserving vector fonts, embedded imagery, and metadata streams.
  • Airgapped Execution: Operates entirely without network requests, telemetry tracking, or temporary disk cache.

Syntax-Driven Page Selection

The page extraction workspace supports both visual tactile selection and flexible syntax expressions. You can input comma-separated page indices or continuous hyphentated ranges (e.g., 1-4, 7, 10-15) for rapid batch workflows.

Each page card features an independent rotation matrix, allowing 90°, 180°, and 270° orientation corrections before final bytecode compilation.

Frequently Asked Questions

Are my confidential PDFs ever sent to a server?

Never. The entire PDF binary parsing, page copying, and compilation sequence takes place within your browser's private WebAssembly memory sandbox.

How do I rearrange documents before merging?

In Merge Mode, use the ↑ and ↓ reorder arrows on each card to set the exact sequence before clicking Compile.

Can I extract just odd or even pages?

Yes. In Split & Extract Mode, use the convenient "ODD" and "EVEN" quick action pills to filter pages with a single click.

Is there a file size or page limit?

Because execution relies on client RAM, standard documents (even 100+ pages) process in seconds.
