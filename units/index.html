BINARY IEC (1024) VS DECIMAL SI (1000) STORAGE METRICS & NETWORK TELEMETRY

Technical analysis of storage radix conventions, the manufacturer capacity mismatch phenomenon, and bit-to-byte throughput formulas.

1. The Radix Dichotomy: IEC vs SI Multipliers

Computing architectures operate natively in base 2 (2¹⁰ = 1,024), while telecommunications and hardware manufacturers use decimal base 10 (10³ = 1,000). In 1998, the International Electrotechnical Commission (IEC 60027-2) standardized prefixes to resolve ambiguity:

  • Binary IEC Prefixes (KiB, MiB, GiB, TiB): Calculated using powers of two: 1 KiB = 1,024 Bytes, 1 MiB = 1,048,576 Bytes, 1 GiB = 1,073,741,824 Bytes, 1 TiB = 1,099,511,627,776 Bytes. Standard in memory allocation, file systems, and operating system kernels.
  • Decimal SI Prefixes (KB, MB, GB, TB): Calculated using powers of ten: 1 KB = 1,000 Bytes, 1 MB = 1,000,000 Bytes, 1 GB = 1,000,000,000 Bytes, 1 TB = 1,000,000,000,000 Bytes. Standard in hard drive retail labeling and network packet headers.

2. Why A 1TB Hard Drive Shows 931 GiB in Windows

When you buy a commercial 1TB hard drive or SSD, the physical platter or flash controller contains 1,000,000,000,000 Bytes. Operating systems like Microsoft Windows calculate volume capacity using binary 1024 division while erroneously appending the SI abbreviation "GB":

// Mathematical Conversion: 1,000,000,000,000 Bytes ÷ 1,024³ = 931.3225746154785 GiB

The drive did not lose storage; rather, the mismatch arises strictly from conflicting numerical radix conventions between hardware manufacturers and software operating systems.
