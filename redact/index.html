CLIENT-SIDE EXIF PURGING // AIRGAP BUFFER

Zero Server Uploads: Local HTML5 Canvas Processing

Unlike online photo editors that transmit your files to remote cloud servers, Privacy Redactor operates entirely in client-side memory through the HTML5 Canvas 2D API. The image data is loaded into local GPU memory, redacted via raster pixel manipulation, and re-encoded using canvas.toBlob(). Zero bytes are transmitted across the internet, guaranteeing zero data leakage for confidential records.

KNOWLEDGE_BASE // FREQUENTLY ASKED QUESTIONS

Image Redaction & EXIF Sanitization FAQs

What EXIF metadata is stripped from exported images?

All embedded metadata blocks — including GPS latitude/longitude coordinates, camera make and model, lens serial numbers, exposure timestamps, shutter counts, and software editing history — are stripped because the exported image is freshly encoded from raw canvas pixel buffers.

Can someone undo or reverse the pixelation or blackout?

No. Some flawed PDF editors merely place a black box layer over text that can be highlighted and copied. In contrast, this tool overwrites the raw pixel values directly on the image raster. Once exported, the obscured data is mathematically destroyed and permanently irreversible.

Does this tool compress or reduce image quality?

Exporting as PNG preserves lossless 1:1 image fidelity with zero compression artifacts. Exporting as JPEG applies a high-fidelity 95% quality rating, offering reduced file sizes suitable for email attachments while maintaining crisp text clarity.
