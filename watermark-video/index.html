TECHNICAL SPECIFICATION // GUARDED IN-MEMORY VIDEO WATERMARKING

Zero-backend, hardware-aware browser video watermarking pipeline utilizing HTML5 Canvas, MediaStream capture, and WebM MediaRecorder.

Client Hardware Guardrails

Video transcode rendering in browser memory places significant demand on client hardware threads. CyberTools detects available CPU cores (navigator.hardwareConcurrency) and memory limits to enforce safe execution constraints.

  • Batch Cap: Maximum of 5 short video clips per session to prevent tab memory overflow.
  • Pre-flight Duration Check: Clips exceeding 120 seconds or 150MB trigger telemetry rejection warnings.
  • Memory Cleanup: Temporary Object URLs are aggressively revoked via URL.revokeObjectURL() immediately following completion.

Pipeline Architecture

The sequential worker decodes each video frame into an offscreen canvas, applies the selected tactical stamp (text, logo, or military-style security badge), and captures the resulting canvas output stream at 30 FPS via canvas.captureStream(30).

The stream is ingested by a hardware-accelerated MediaRecorder instance encoding to WebM (VP9/VP8) or MP4 containers, producing clean, self-contained video files without transmitting a single byte to external servers.

Frequently Asked Questions

Are my video files uploaded to any server?

No. Processing is completely airgapped within your local browser memory using HTML5 canvas and MediaRecorder APIs. No telemetry or binary chunks ever leave your machine.

Why is there a 120-second duration limit?

Encoding high-definition video frames in JavaScript generates large memory buffers. The 120-second cap prevents browser tab crashes, Out-of-Memory (OOM) faults, and mobile device lockups.

What happens if I click Abort Pipeline?

The abort trigger immediately calls MediaRecorder.stop(), pauses all playback streams, releases allocated blob buffers, and resets the interface state safely.

Can I position the watermark anywhere on the screen?

Yes. Use the 9-point anchor snap grid combined with horizontal and vertical offset sliders to align the stamp with precision.
