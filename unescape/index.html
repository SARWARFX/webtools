1. Lexical Escape Dialects

        

          Different runtime environments use distinct syntaxes to represent control codes, quote boundaries, and non-printable characters:
        

        
    
          
  • JSON & ECMAScript: Uses the reverse solidus (\). Standard escapes include newline (\n), carriage return (\r), horizontal tab (\t), escaped quotes (\"), and hexadecimal unicode points (\uXXXX).
    • 
          
  • HTML Entities: Employs ampersand-terminated entity names or codepoints to prevent Cross-Site Scripting (XSS) and parser corruption. Core entities: &amp;, &lt;, &gt;, &quot;, and &#39;.
    • 
          
  • SQL Literal Quotes: Under standard ANSI SQL, a single quote (') inside a string literal is escaped by doubling it (''). MySQL and PostgreSQL also support backslash escaping depending on standard compliance mode.
    •
