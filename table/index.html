1. Core Markdown Table Syntax

        

          Standard Markdown syntax (originally standardized by GitHub Flavored Markdown and CommonMark extensions) defines tables using vertical pipes (|) to separate cells and hyphens (-) to construct the delimiter row separating column headers from table rows:

2. Column Alignment Notation

        

          Text alignment is specified entirely within the second row (the delimiter row) using colons (:):
        

        
    
          
  • Left-Aligned (:---): Colon on the far left. Aligns content flush to the left boundary. This is also the default behavior when colons are omitted.
    • 
          
  • Center-Aligned (:---:): Colons on both the left and right extremities. Centers cell text and numbers symmetrically.
    • 
          
  • Right-Aligned (---:): Colon on the far right. Ideal for financial columns, numeric telemetry, percentages, and currencies.
    • 
        

      


      

        
3. Whitespace Padding & Code Prettification

        

          While Markdown renderers do not require vertical pipes to be visually aligned, unaligned tables become unreadable in raw Git diffs, terminal outputs, and code editors. This generator dynamically computes the maximum byte width of each column (including alignment headers) and injects precise space padding so raw tables remain clean and human-readable.
