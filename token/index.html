1. Math.random() vs Cryptographic CSPRNG

Standard JavaScript Math.random() relies on pseudorandom number generators like xorshift128+ that are completely deterministic and vulnerable to state-recovery attacks. After observing just a few sequential outputs, attackers can reconstruct internal PRNG states and predict future tokens.

This utility strictly utilizes the window.crypto.getRandomValues() API, which pulls entropy directly from host operating system kernels (/dev/urandom on Linux/macOS and BCryptGenRandom on Windows), incorporating hardware interrupt jitter and CPU thermal noise.
