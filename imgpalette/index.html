1. Color Quantization via Canvas API

Raster images contain upwards of millions of discrete RGB pixel coordinates. To synthesize a cohesive 6-color palette, our engine draws bitmap payloads onto an in-memory downsampled 100×100 canvas. Accessing raw RGBA octets via ctx.getImageData(0, 0, w, h).data enables spatial color binning across three-dimensional Euclidean RGB distance:

// Euclidean Color Distance: ΔE = √[ (R&sub1; - R&sub2;)² + (G&sub1; - G&sub2;)² + (B&sub1; - B&sub2;)² ]

2. WCAG Relative Luminance Standards

Per W3C Web Content Accessibility Guidelines (WCAG 2.1), relative luminance measures normalized photometric brightness:

Y = 0.2126 × R_lin + 0.7152 × G_lin + 0.0722 × B_lin
