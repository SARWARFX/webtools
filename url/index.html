FREQUENTLY ASKED QUESTIONS

Q: What is the difference between encodeURI and encodeURIComponent?
`encodeURI` preserves protocol and path delimiters like `:`, `/`, `?`, and `#`. `encodeURIComponent` encodes all reserved characters for safe insertion into a query parameter.

Q: Can I edit parameters in the table to rebuild the URL?
Yes. Editing any key or value in the query parameter table instantly re-serializes the complete URL in the main input box.
