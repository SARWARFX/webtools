Cryptographic Checksum & Hash Verification Protocol

Complete client-side cryptographic hashing sandbox leveraging the W3C Web Cryptography API and isolated V8 ArrayBuffer memory.

01 / AIRGAP INTEGRITY

Your data and files never leave your device. All hashing runs locally inside your browser's WebCrypto worker threads. No server transfers, no telemetry, zero logs.

02 / HARDWARE ACCELERATED

SHA-256 and SHA-512 computations utilize native hardware instruction sets (Intel SHA extensions / ARMv8 Crypto) via `crypto.subtle` for gigabyte-per-second throughput.

03 / HMAC SIGNING

Keyed-hash message authentication code (HMAC) mode provides cryptographic message authentication using secret keys conforming to RFC 2104.

FREQUENTLY ASKED QUESTIONS

Q: Can I verify large ISOs or software releases?
Yes. The file hasher reads local files directly in browser memory using chunked ArrayBuffers, allowing verification of multi-gigabyte files with zero network upload.

Q: Which hash algorithm should I use for security?
SHA-256 and SHA-512 are industry standard and collision-resistant. MD5 and SHA-1 should only be used for legacy checksum verification or deduplication.
