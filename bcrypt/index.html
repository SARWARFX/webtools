Bcrypt is an adaptive key derivation function based on the Blowfish symmetric block cipher designed by Niels Provos and David Mazières in 1999:

Adaptive Cost Factor The round count parameter $2^R$ doubles the CPU cycles required for every unit increment, ensuring defense against future GPU/ASIC hardware advances.
Built-in Salt A 128-bit cryptographically secure salt is pre-computed and concatenated into the 60-character result string, neutralizing rainbow table attacks.
Zero-Upload Privacy Hashing executes within browser thread memory via client JavaScript. Passwords never traverse network pipes.
