Catastrophic Backtracking (ReDoS) Protection

Non-deterministic Finite Automaton (NFA) regular expression engines (standard in JavaScript V8, SpiderMonkey, and JavaScriptCore) explore recursive match states. When poorly constructed patterns with overlapping quantifiers (e.g. (a+)+$) encounter non-matching input strings, the engine's time complexity increases exponentially ($O(2^n)$), causing the browser tab to freeze completely.

Regex Scanner integrates an execution circuit-breaker: iterations of RegExp.exec() are bound by a 5,000-match ceiling and benchmark timers, immediately terminating problematic evaluations to safeguard client browser threads.

Numbered vs. Named Capture Groups

Parentheses in regular expressions create capture groups. Numbered capture groups are indexed sequentially starting at $1 from left to right based on the opening parenthesis. Modern ECMAScript engines also support named capture groups via the syntax (?<groupName>...), allowing structured object extraction directly into match.groups.

Non-capturing groups (?:...) provide logical grouping and alternation without assigning memory slots in the capture array, reducing memory footprint during high-frequency parsing.
