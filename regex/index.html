FREQUENTLY ASKED QUESTIONS

Q: What modifier flags are supported?
All standard modern JavaScript flags: `g` (global), `i` (case-insensitive), `m` (multiline `^` and `$`), `s` (dotAll wildcard matches `\n`), and `u` (full unicode code points).

Q: Can I use substitution variables in replacement?
Yes. Supports `$1`, `$2` for capture groups, `$&` for the whole match, and `$`` / `$'` for the preceding/following text.
