Display Media & Audio Mixing

Modern Chromium, Firefox, and WebKit browsers expose the Screen Capture API through navigator.mediaDevices.getDisplayMedia(). This allows client scripts to request permission to record entire displays, specific application windows, or browser tabs at framerates up to 60 FPS without installing third-party desktop software or extensions.

When both system tab audio and microphone narration are activated simultaneously, an in-memory AudioContext combines both independent stream sources via a MediaStreamAudioDestinationNode, synchronizing high-fidelity audio tracks with the outgoing video stream.

Zero-Telemetry Privacy Assurance

Unlike commercial screen recording SaaS platforms that stream captured frames to cloud storage backends, CyberTools processes video streams strictly inside browser memory. Video and audio chunks received via the MediaRecorder.ondataavailable event are accumulated in a local JavaScript array and compiled into an in-memory Blob.

No audio samples, video keyframes, or session metadata ever leave your computer. Once downloaded or discarded, memory buffers are immediately freed via URL.revokeObjectURL().
